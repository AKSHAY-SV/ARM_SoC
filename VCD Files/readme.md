# VCD Waveform Files

This folder contains Value Change Dump (`.vcd`) files generated during RTL simulation.

VCD files record signal transitions over simulation time and can be opened using GTKWave or another compatible waveform viewer.

---

## Contents

### `apb_interconnect.vcd`

Waveform dump for APB address decoding and peripheral routing.

---

### `apb_subsystem.vcd`

Waveform dump for the complete APB subsystem.

---

### `axi_decoder.vcd`

Waveform dump for the SoC address decoder.

---

### `gpio_apb.vcd`

Waveform dump for GPIO APB transactions and GPIO control signals.

---

### `plic_simple.vcd`

Waveform dump for interrupt pending, clearing, and processor interrupt signaling.

---

### `ram.vcd`

Waveform dump for RAM accesses.

---

### `rom.vcd`

Waveform dump for ROM and boot-memory accesses.

---

### `soc_tb.vcd`

Main full-SoC verification waveform generated by the SystemVerilog testbench.

---

### `soc_top.vcd`

Waveform dump for the integrated SoC top-level design.

---

### `spi_master_apb.vcd`

Waveform dump for SPI transactions and serial communication signals.

---

### `timer_apb.vcd`

Waveform dump for timer operation and interrupt generation.

---

### `top.vcd`

Waveform dump for processor-level simulation.

---

### `top_isa_regression.vcd`

Waveform dump generated during processor ISA regression.

---

### `uart_final.vcd`

Waveform dump for final UART integration and serial communication.

---

# Viewing Waveforms

The VCD files can be opened using GTKWave.

Example:

```bash
gtkwave soc_tb.vcd
